# Assets

Placez ici les images nécessaires à l'application :

## Fichiers requis

- `icon.png` - Icône de l'app (1024x1024px)
- `splash.png` - Écran de chargement (1284x2778px)
- `adaptive-icon.png` - Icône Android adaptive (1024x1024px)
- `favicon.png` - Favicon pour le web (48x48px)

## Création des icônes

Vous pouvez utiliser un générateur d'icônes comme :
- https://easyappicon.com/
- https://appicon.co/

Couleur de fond recommandée : `#0f0f1a`
